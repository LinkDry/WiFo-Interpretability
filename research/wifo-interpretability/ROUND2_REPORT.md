# WiFo Base Round 2 实验报告

2026-11-27

冻结 WiFo v1 Base，在第一层解码器测试注意力图与 Value 的配对反事实替换，同时在各剪枝预算上测量联合头消融。所有区间为 2,000 次配对 bootstrap 的 95% 区间。

## 第一层解码器的注意力图与 Value 替换

沿用两套 Base pilot 合成多径，每套 128 个配对信道，RMS 多普勒 40/140 Hz × RMS 时延扩展 50/200 ns。每个受体与供体只差一个物理因素，掩码和标准噪声抽样沿用原协议。按四个受体条件平均各自的 NMSE 变化（dB），时域轴选择性为多普勒代价减时延代价，频域反之。

Identity 与原始推理的最大逐样本线性 NMSE 差为 1.8e-07。同样本 A-only 也通过 Round 1 原始结果的数值回归检查。

## 联合头消融与阈值锁定

两项任务分别按 D7/D16 发现集的平均单头 ΔNMSE 升序排列。整条前缀曲线覆盖所有整数头数 0–80，以 D7/D16 留出集点估计的最坏域退化锁定满足预算的最大头数。表中的验证区间固定已选头组，选择过程使用点估计。Global Taylor 用逐样本的门控梯度绝对值，除以对应域和任务的平均线性基线 NMSE，再对发现域与两项任务等权平均。Same-Layer Random 每项用 10 个预先锁定的随机种子，逐层数量与 Task-Aware 一致。

| 任务 | 容限 | 头数 | Enc1 / Enc2–6 / Dec1 / Dec2–4 | 留出集最坏 ΔNMSE |
|---|---:|---:|---|---:|
| temporal | 0.1 dB | 8/80 | 0 / 7 / 0 / 1 | +0.084 [+0.042, +0.176] |
| temporal | 0.2 dB | 16/80 | 0 / 14 / 0 / 2 | +0.185 [+0.109, +0.308] |
| temporal | 0.5 dB | 22/80 | 1 / 19 / 0 / 2 | +0.495 [+0.346, +0.667] |
| fre | 0.1 dB | 19/80 | 3 / 15 / 0 / 1 | +0.081 [+0.033, +0.148] |
| fre | 0.2 dB | 23/80 | 3 / 19 / 0 / 1 | +0.183 [+0.095, +0.282] |
| fre | 0.5 dB | 33/80 | 4 / 28 / 0 / 1 | +0.447 [+0.311, +0.609] |

锁定头组后，D17、D18 各从 Round 1 未使用的索引中再取 160 个样本。最坏域取两个域的 ΔNMSE 最大值。同层随机法先取种子均值，再取最坏域。其区间对种子和域内样本共同重采样，两个域使用同一组抽中的种子。

| 任务 | 容限 | 头数 | 方法 | D17 ΔNMSE | D18 ΔNMSE | 最坏域 ΔNMSE |
|---|---:|---:|---|---:|---:|---:|
| temporal | 0.2 dB | 16 | Task-Aware | +0.262 [+0.121, +0.425] | +0.172 [+0.106, +0.238] | +0.262 [+0.153, +0.425] |
| temporal | 0.2 dB | 16 | Global Taylor | +0.110 [+0.047, +0.171] | +0.113 [+0.056, +0.168] | +0.113 [+0.080, +0.176] |
| temporal | 0.2 dB | 16 | Same-Layer Random | +0.322 [+0.216, +0.435] | +0.182 [+0.110, +0.259] | +0.322 [+0.220, +0.435] |
| fre | 0.2 dB | 23 | Task-Aware | +0.055 [-0.032, +0.124] | +0.147 [+0.095, +0.199] | +0.147 [+0.096, +0.199] |
| fre | 0.2 dB | 23 | Global Taylor | +0.133 [+0.027, +0.214] | +0.142 [+0.092, +0.194] | +0.142 [+0.106, +0.215] |
| fre | 0.2 dB | 23 | Same-Layer Random | +1.602 [+1.175, +2.073] | +0.790 [+0.628, +0.986] | +1.602 [+1.175, +2.073] |

- `temporal` 在 0.2 dB 验证预算下锁定 **16/80** 个头，盲测最坏域退化 **0.262 dB**，点估计高于 0.2 dB。
- `fre` 在 0.2 dB 验证预算下锁定 **23/80** 个头，盲测最坏域退化 **0.147 dB**，点估计低于或等于 0.2 dB。
- 在相同头数下，Global Taylor 相对 Task-Aware 的最坏域退化差为时域 -0.149 [-0.301, -0.031] dB、频域 -0.005 [-0.037, +0.080] dB。频域 Same-Layer Random 相对 Task-Aware 的差为 +1.455 [+1.011, +1.929] dB。

参考预算的盲测结果及相对 Task-Aware 的配对差见 [盲测结果表](results/round2_av_prune/pruning_blind_eval.csv)。[锁定的头组与随机种子](results/round2_av_prune/prune_lock.json) 和 [完整联合消融曲线](results/round2_av_prune/pruning_curve.csv) 可用于复核。以上头数均基于运行时联合屏蔽。
