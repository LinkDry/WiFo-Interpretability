# WiFo Base 时频注意力头预实验

2026-11-27

在 D7、D16 的留出样本以及 D11、D17、D18 上，锁定的两组注意力头均表现出可复现的任务偏好。第一层解码器同时包含一个对两任务均有较大影响的头。双轴物理反事实进一步发现，任务偏好与注意力图的物理轴选择性可以分离。

## 时域与频域任务上的干预效应

冻结 WiFo v1 Base，逐头消融 6 层 encoder 和 4 层 decoder 的 80 个头。D7、D16 各使用 160 个公开测试样本发现候选，再各留出 160 个独立样本。D11、D17、D18 各取 160 个样本。使用 50% 的官方任务遮罩，按每个样本可见 CSI 功率设定 20 dB 输入噪声，同任务同样本的消融共用同一份噪声。以干净掩码区为目标。效应量是消融和完整模型的平均线性 NMSE 之比转 dB。正值表示误差上升。区间按样本配对 bootstrap 2,000 次。

发现集按单头的时频消融效应差排序，分别锁定两端各 4 个头。`Dec1-H2` 表示第一层解码器第 2 个头。时域组为 Dec1-H2、Dec4-H6、Dec1-H4、Dec1-H6。频域组为 Dec1-H3、Dec1-H8、Enc1-H2、Dec1-H7。在 D7/D16 留出集上，80 个头的效应差排名与发现集的 Spearman ρ 为 0.868。D11 为 0.762。

| 复核集 | 时域任务中，移除时域组比移除频域组多升高的 NMSE | 频域任务中，移除频域组比移除时域组多升高的 NMSE |
|---|---:|---:|
| D7 留出 | 8.66 dB [8.16, 9.17] | 4.34 dB [3.85, 4.85] |
| D16 留出 | 4.24 dB [3.85, 4.66] | 2.81 dB [2.58, 3.04] |
| D11 | 5.59 dB [5.14, 6.04] | 3.20 dB [2.92, 3.50] |
| D17 | 4.48 dB [4.08, 4.90] | 2.89 dB [2.65, 3.14] |
| D18 | 3.33 dB [2.96, 3.71] | 2.21 dB [1.95, 2.49] |

在 D16 留出样本上，关闭 Dec1-H2 使时域和频域 NMSE 分别增加 4.42、0.45 dB。关闭 Dec1-H3 的对应增量为 0.20、1.05 dB。关闭 Dec1-H1 的对应增量为 4.13、5.52 dB。频域组按时频效应差选出，按频域损害绝对值排序时，这组在每个划分均落后于 12 组同层随机对照。随机组可以抽到 Dec1-H1 等两任务共同依赖的头。

D17、D18 上移除异任务头组的 NMSE 代价分别为时域 0.67、0.29 dB 和频域 0.52、0.44 dB。按原设想的 0.2 dB 容限，直接移除两组异任务头的策略在这四个条件下均超出预算。

## RMS 多普勒与 RMS 时延扩展的配对反事实

用两种参数化多径生成规则构造各 128 个基础信道，一种为分散路径，一种带延迟簇。每个基础信道复用阵列、路径增益、方向与噪声的标准随机样本，组合 RMS 多普勒 40/140 Hz 和 RMS 时延扩展 50/200 ns，形成 4 个条件。固定 16×32×32 网格、0.5 ms 快照和 180 kHz 子载波间距。RMS 多普勒是路径功率加权的谱展宽。对 decoder 的跨度分析使用待预测查询及其可见键并按均匀可达跨度归一化。物理因素效应按这两个预选水平估计。

替换干预使用同一基础信道的另一物理条件作为注意力图供体，在替换点保留受体的 Value。接收自身注意力图的对照通过数值等价检查。两种因素分别替换，性能差按另一因素和替换方向平均。

| 多径设置 | 时域任务的候选组相对同层对照增加的多普勒选择性 | 频域任务的候选组相对同层对照增加的时延选择性 |
|---|---:|---:|
| 分散路径 | −0.077 dB [−0.097, −0.057] | −0.001 dB [−0.012, 0.010] |
| 延迟簇 | −0.067 dB [−0.100, −0.035] | +0.041 dB [0.026, 0.056] |

时域候选组的归一化时域跨度随 RMS 多普勒的变化在两种路径设置下区间均跨零。频域候选组在分散路径上的频域跨度随时延扩展略增，在延迟簇设置下区间跨零。注意力跨度的点估计依赖所用头组和路径结构。

为检查随机对照抽样的影响，进一步替换了第一层解码器全部 8 个头的注意力图。两种路径设置中，Dec1-H3 均有该层最大的时延轴选择性，其时域任务的多普勒轴选择性在该层也最高。对这个层的观察来自同一批合成信道，应作为后续物理实验的选点依据。

## 复现

在本研究目录运行。第二次完整运行用新结果目录。

```powershell
python -m unittest -v test_wifo_pilot
python wifo_pilot.py --output results/repeat_pilot --samples 160 --physics-samples 128 --batch 16 --chunk 8 --physics-batch 8
python summarize_pilot.py results/repeat_pilot
python decoder_swap_audit.py results/repeat_pilot
```

`results/base_pilot/run.json` 保存权重哈希、代码提交、设备、样本量及模拟设置。`heads_*.npz` 和 `groups_*.npz` 保存样本索引与逐样本 NMSE。`physics_*.npz` 保存多径参数、跨度与替换效应。`decoder_l1_swaps.csv` 为第一层解码器的逐头替换复核。

这轮测试覆盖一个模型权重和两套合成路径分布。建议下一轮对 Dec1-H1/H2/H3 分别交换注意力图与 Value，并在 QuaDRiGa 轨迹上比较物理轴选择性。若推进剪枝，按验证集误差预算累积移除低敏感度头，并检查锁定预算在 D17/D18 的最坏退化。
